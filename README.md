# KYIV — Digital City

Україномовний багатосторінковий інформаційний портал про Київ. Статичний проєкт на HTML, CSS і JavaScript, сумісний із GitHub Pages.

## Запуск
Відкрийте `index.html` у браузері або запустіть локальний статичний сервер (наприклад, VS Code Live Server).

## Публікація на GitHub Pages
1. Відкрийте **Settings → Pages** у репозиторії.
2. У **Build and deployment** оберіть **Deploy from a branch**.
3. Вкажіть гілку `main` та папку `/ (root)), натисніть **Save**.
4. Після завершення розгортання сайт буде доступний за адресою GitHub Pages репозиторію.

## Структура
- `index.html` — головна.
- `pages/` — 20 тематичних сторінок.
- `css/style.css` — адаптивний дизайн і теми.
- `js/main.js` — навігація, пошук, фільтри, карта, графіки та контент.

## Важливо про дані
Статистичні значення мають супроводжуватися роком і джерелом. Там, де актуальні порівнювані дані відсутні або воєнні умови унеможливлюють коректну оцінку, портал прямо позначає це замість вигадування чисел. Зовнішні фотографії, карти й бібліотеки завантажуються з відповідних сервісів за наявності інтернету.

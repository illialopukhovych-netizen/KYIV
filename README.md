# KYIV — Digital City

Україномовний багатосторінковий портал про Київ. Статичний HTML/CSS/JavaScript, сумісний із GitHub Pages.

## Публікація
1. Відкрийте Settings → Pages.
2. Оберіть Deploy from a branch, гілку `main` і папку `/ (root)`.
3. Натисніть Save та дочекайтеся розгортання.

## Структура
- `index.html` — головна.
- `pages/` — тематичні розділи.
- `css/style.css` — адаптивний дизайн.
- `js/main.js` — навігація, пошук, тема, карта.
- `js/content.js` — дані розділів і районів.

## Примітка
Не додавайте неперевірені статистичні значення. Для кожного показника вказуйте рік, одиницю, методику та першоджерело. Leaflet і тайли OpenStreetMap завантажуються з мережі.
